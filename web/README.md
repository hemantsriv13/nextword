# NextWord Lab interface

The browser half of the Lab. See [../docs/LAB.md](../docs/LAB.md) for how to build and run it.

- `src/workspaces/`: one file per workspace.
- `src/sim/`: browser simulations, each with a `*.test.ts` (`npm test`).
- `src/components/lab/`: shared Lab components; `src/components/ui/`: the installed design-system kit.
- `src/content/`: glossary, learning journey and texts.
